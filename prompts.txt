/skill:harmony-card-generation-datamodel-first

【数据源】datasets/cases-10k/10000Cases.tagged.jsonl
  每行一条 JSON record,字段:
    - scenario:        场景 id,如 "01-low-power"
    - scenario_name:   场景中文名,如 "低电模式"
    - query:           用户原始 Query 文本
    - axes:            覆盖配置对象(参考用,不强制)
  共 10000 条 record,涵盖 30 个场景。

【调度策略】
- 每条 case 启一个独立的 subAgent(保证上下文纯净,SubAgent 之间互不干扰)
- 任意时刻最多 5 个 subAgent 并行存在
- 共 10000 条 case,按"5 并行窗口"串行分批处理
- SubAgent 失败的 case 写 error.txt 占位,不中断队列

【SubAgent 单条任务】
对分到的一条 record,SubAgent 完整执行以下步骤:

1. 从 record 读取 scenario / scenario_name / query / axes 四个字段。

2. 依据 TaskSpec 协议(taskspec.schema.json)把 query 抽取成轻量 TaskSpec:
   - size: "2x2" 或 "2x4"(根据 query 复杂度自行判断)
   - eventCandidates: 从 query 自然语言意图中抽取可触发的 clickToCallPhone /
     clickToDeeplink(settings/weather/clock/music/health) /
     clickToIntent(ViewCalendarEvent/StartNavigate/SetSettingSwitch) 候选
   - dataModel.value: query 涉及的关键数据字段(电量/步数/比分/天气等)
   - assetCandidates: 原 11 场景可引用素材库(resources/base/media/)图标;
     扩展场景不引用具体图片素材,只描述数据/布局/动作

3. 调 harmony-card-generation-datamodel-first skill,把 TaskSpec 转换为
   3 行 JSONL 的 genui DSL(2x2 或 2x4 卡片)。

4. 写一个简单的 CardSpec 摘要:
   {"suggestSize": "<与 DSL 一致的 2x2 或 2x4>"}
   静态卡片不虚构 dataBindings。

5. 按以下结构落盘 5 个文件到
   datasets/Scenario/cases-10k-gpt-5.5/<scenario_id>/Case-NNN/
   (NNN 是场景内从 001 开始的三位编号,按 record 顺序连续):
     - query.txt            # 原始 Query 文本
     - task.taskSpec.json   # 步骤 2 产出的 TaskSpec
     - card.dsl.jsonl       # 步骤 3 产出的 3 行 JSONL DSL
     - card.cardspec.json   # 步骤 4 产出的 CardSpec 摘要
     - notes.md             # 可选,记录布局理由/改进

6. 若本条执行失败,改写 error.txt(包含失败原因)并跳过;不影响后续 case。

【完成报告】
全部 10000 条 case 处理完毕后,在主流程输出:
- 成功 case 数
- 失败 case 数(error.txt 占位)
- 失败原因分类统计(如 DataModel 解析失败、布局溢出、组件越界等)
- 各场景实际完成数 vs 期望配额

【硬约束】
- 不修改 .agents/skills/ 下的任何 skill 文件
- 不修改 taskspec.schema.json / taskspec_to_chat_completions.py 等基础设施
- 严格遵循 DataModel-first 协议:展示值优先用完整表达式 {{ ... }} 读取 DataModel
- 卡片 size 只能是 2x2 或 2x4,不允许 1x2 / 4x4 等其它尺寸
- 禁止使用 TextInput / Toggle / Radio / Tabs / Web / Grid / If 等被禁组件
- 不使用网络图、SVG、emoji、占位图

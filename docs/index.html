把 Form 协议约束抽取出来，让小模型更会画卡片

CartTaskSpec 不是把理解力简单交给大模型，而是让大模型从用户 query 中抽取与 Form 协议相关的约束、能力和交付契约；小模型在清晰边界内完成真正有价值的 DSL 设计与生成。

Large Model

抽取约束，而不是写死布局

识别场景、尺寸、数据能力、事件能力、CardSpec 和 DSL 硬规则。

Small Model

在约束内完成高质量实现

完成组件组织、视觉层次、排版、绑定和最终 3 行 genui JSONL。

Final Artifact

CardSpec 前置确定，小模型不再生成 cardspec。

Design Philosophy

协议设计思想

TaskSpec 的核心不是替小模型完成布局，而是把 Form 卡片生成中必须遵守的协议规则、数据契约和事件边界整理成一个短小、可校验的输入。

1

从 query 抽取 Form 约束

大模型的价值在于把自然语言需求变成结构化约束：显示字段、动态能力、点击能力、CardSpec、禁止项和输出格式。

2

保留小模型的设计空间

TaskSpec 不携带布局树、区域预算或组件嵌套。小模型负责把需求转成可渲染、可读、可交互的 DSL。

3

用校验兜住边界

小模型可以发挥布局和视觉能力，但必须通过 JSONL、组件、绑定、事件、DataModel 和尺寸校验。

大模型负责抽取什么？

不是产出完整卡片，而是把与协议有关的决策抽出来。

  • 内容约束：哪些信息必须出现、哪些字段要完整显示。
  • 能力约束：data capability、event capability、参数和写入路径。
  • 交付约束：cardSpec、rules.dsl、输出禁止项。

小模型的核心价值是什么？

小模型不是剩下组装，而是在明确约束内完成卡片设计落地。

  • 布局判断：根据 2x2/2x4 空间组织信息层级。
  • 组件实现：选择 Row/Column/Stack/Text/Button 等并生成扁平组件数组。
  • 视觉表达：处理留白、字号、颜色、层次、点击区域和拥挤文本。
  • 协议落地：输出严格 3 行 JSONL，并保持 DataModel 和事件绑定一致。
Workflow

分层作业流

不用复杂连线。整个流程按职责分成四层：约束抽取层、协议校验层、DSL 生成层、交付校验层。每层输入输出清楚，互不越界。

Layer 01约束抽取层

输入用户 query

一句话需求，可能包含场景、数据、动作、风格。

抽取 Form 约束

识别尺寸、必显字段、能力、事件和禁止项。

产出 TaskSpec

轻量 JSON：requirements、dataModel、cardSpec、rules.dsl。

Layer 02协议校验层

Schema 校验

确保 TaskSpec 字段形状符合 taskspec.schema.json。

引用一致性

检查 dataPath、eventRef、assetRef、dataBindings 对齐。

项目约束

确认 .agents/skills 只读，没有被修改。

Layer 03DSL 生成层

生成请求体

转换成 chat-completions：system prompt + user TaskSpec。

小模型设计布局

小模型根据约束完成组件层级、视觉和交互实现。

输出 genui

只输出一个 genui 代码块，恰好 3 行 JSONL。

Layer 04交付校验层

校验模型输出

检查 JSONL、组件、root 尺寸、DataModel 一致性。

透传 cardSpec

TaskSpec.cardSpec 直接作为端侧能力契约。

组合交付

最终结果为 genui DSL + TaskSpec.cardSpec。

Protocol Sample

协议样例

TaskSpec 只描述内容项和约束，不写具体布局。切换查看父母关怀卡、耳机桌面卡和 chat-completions 请求体。

Commands

          
常用命令

        

        

          

            
校验 TaskSpec 与项目约束

            
python validate_taskspec.py examples
python validate_project_constraints.py

          

          

            
生成请求体并请求模型

            
python taskspec_to_chat_completions.py examples\parent-care.taskspec.json `
  -o request.json --invoke --response-output response.json

          

          

            
校验并提取 genui

            
python validate_generated_card.py `
  --response response.json `
  --spec examples\parent-care.taskspec.json `
  --out-dir generated --name parent-care

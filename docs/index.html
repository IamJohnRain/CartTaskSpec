TaskSpec 协议

Top Level

字段简介

当前 schema 顶层只允许 5 个业务字段，全部必填。

字段是否必须说明示例
userQuery必须原始用户需求，保留语义来源。"显示深圳温度并给我爸打电话"
size必须目标尺寸，取值为 2x2 或 2x4。"2x4"
eventCandidates必须候选事件能力，只包含 call/args；最终 DSL 才生成 onClick。[{"call":"clickToDeeplink"}]
dataModel必须A2UI 模型第 3 行 updateDataModel.value 必须原样使用的数据。{"value":{"device":{...}}}
assetCandidates必须素材候选白名单；description 说明素材内容和适用场景。[]
Modules

具体模块说明

MODULE 01

eventCandidates

候选事件能力

必须 只提供候选事件的 call/args。A2UI 模型从 userQuery 判断入口文案和挂载位置，并在最终 DSL 中生成 onClick。

示例
[
  {
    "call": "clickToDeeplink",
    "args": { "bundleName": "", "abilityName": "", "uri": "..." }
  }
]
MODULE 02

dataModel

表达式和绑定的唯一数据源

必须 `dataModel.value` 必须被 A2UI 模型原样写入 `updateDataModel.value`。

示例
{
  "value": {
    "device": {
      "name": "Free Clip 2",
      "leftBatteryText": "左耳 47%",
      "rightBatteryText": "右耳 95%"
    }
  }
}
MODULE 03

assetCandidates

素材候选白名单

必须 没有素材时写 `[]`。素材项必须包含 description，说明素材内容、视觉语义和适用场景。

示例
[
  { "assetRef": "earbuds_icon", "src": "assets/freeclip2-earbuds.png", "use": "device illustration", "description": "Free Clip 2 耳机图形素材，适合用于设备识别或轻量装饰。", "static": true }
]
System Prompt

当前 system prompt 说明

TaskSpec 不携带 DSL 硬规则。转换脚本把这些规则集中写入 chat-completions 的 system 消息，让 A2UI 模型在稳定边界内完成设计与 DSL 生成。

输入与输出边界

  • 角色是 A2UI 模型，负责生成 HarmonyOS A2UI Form DSL。
  • TaskSpec 不是布局蓝图，也不提供展示内容清单。
  • 输出一个 `genui` 代码块，恰好 3 行 JSONL。

DSL 硬规则

  • `size=2x2` 对应 140x140，`2x4` 对应 300x140。
  • 只允许 Text、Image、Divider、Progress、Button、Checkbox、Row、Column、List、Stack。
  • 展示值优先使用完整表达式读取 DataModel。
  • 最终 DSL 的 onClick 只能由 eventCandidates 转换而来，图片只能来自 assetCandidates 或明确本地资源。
system prompt 摘要
你是 A2UI 模型，负责依据 harmony-card-generation-datamodel-first 的协议生成 HarmonyOS A2UI Form 卡片 DSL。
你会收到一个 TaskSpec JSON。TaskSpec 只提供用户原始需求、目标尺寸、DataModel、可点击事件候选和素材候选；它不是卡片布局方案。
A2UI 模型从 userQuery 和 dataModel.value 中自行判断需要展示的信息。
eventCandidates 只是候选事件能力，最终 DSL 才生成 onClick。
输出一个 ```genui``` 代码块，内容为 3 行 JSONL。
genui 必须恰好 3 行 JSONL，顺序是 createSurface、updateComponents、updateDataModel。
展示值优先使用完整表达式读取 DataModel；点击和素材只能来自 TaskSpec 声明。
Validation

校验要点

发送给 A2UI 模型前

  • JSON 结构符合 `taskspec.schema.json`。
  • `eventCandidates[].call/args` 必须合法。
  • `eventCandidates[]` 不允许出现 id、label、description、required 或 onClick。
  • `assetCandidates[].description` 必须非空。

模型输出后

  • 包含一个 `genui` 代码块。
  • genui 恰好 3 行 JSONL。
  • `updateDataModel.value` 等于 `TaskSpec.dataModel.value`。
  • root 尺寸为 140x140 或 300x140。

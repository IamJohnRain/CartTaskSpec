TaskSpec Protocol · DataModel-first

TaskSpec 是 A2UI DSL 的候选约束输入

大模型 Agent 从用户 query 中抽取内容候选、事件候选、素材候选、DataModel 和目标约束；A2UI 模型负责完成组件组织、视觉表达和最终 genui DSL。

DSL-only交付物是 genui DSL。
DataModel-first展示值优先使用完整表达式读取 DataModel。
规则进 promptsystem prompt 承载 DSL 硬规则。
动作内联event candidate 直接携带 onClick。
Top Level

顶层字段与是否必填

当前 schema 顶层只允许 7 个业务字段，全部必填。

字段是否必须说明示例
userQuery必须原始用户需求，保留语义来源。"显示深圳温度并给我爸打电话"
task必须给 A2UI 模型的任务说明，必须约束只输出 genui。"直接输出 genui..."
target必须目标尺寸、场景弱提示、风格提示和约束。{"size":"2x4","styleHints":[...]}
displayCandidates必须可显示的信息候选，不是组件候选。[{"role":"metric"}]
eventCandidates必须可点击事件候选，不规定按钮形态。[{"label":"每日30首"}]
dataModel必须A2UI 模型第 3 行 updateDataModel.value 必须原样使用的数据。{"value":{"device":{...}}}
assetCandidates必须素材候选白名单；没有素材时为空数组。[]
Modules

具体模块说明

MODULE 01

target

目标弱约束

必须 描述目标尺寸、场景提示、风格提示和业务约束。

示例
{
  "size": "2x4",
  "sceneHints": ["device", "music"],
  "styleHints": ["简洁高级", "磨砂玻璃质感"]
}
MODULE 02

displayCandidates

内容候选

必须 表达可显示的信息候选，由 A2UI 模型决定最终组件形态。

示例
[
  { "id": "device_name", "role": "identity", "label": "Free Clip 2", "dataPath": "/device/name", "required": true },
  { "id": "left_battery", "role": "metric", "label": "左耳电量", "dataPath": "/device/leftBatteryText", "required": true }
]
MODULE 03

eventCandidates

事件候选，不规定按钮形态

必须 表达可点击事件能力。A2UI 模型决定最终是 Button 还是可点击容器。

示例
[
  {
    "id": "daily_30",
    "label": "每日30首",
    "required": true,
    "onClick": [{ "call": "clickToDeeplink", "args": { "bundleName": "", "abilityName": "", "uri": "..." } }]
  }
]
MODULE 04

dataModel

表达式和绑定的唯一数据源

必须 `dataModel.value` 必须被 A2UI 模型原样写入 `updateDataModel.value`。

示例
{
  "value": {
    "device": {
      "name": "Free Clip 2",
      "leftBatteryText": "左耳 47%",
      "rightBatteryText": "右耳 95%"
    }
  }
}
MODULE 05

assetCandidates

素材候选白名单

必须 没有素材时写 `[]`。它不规定素材最终做背景、图标还是插图。

示例
[
  { "assetRef": "earbuds_icon", "src": "assets/freeclip2-earbuds.png", "use": "device illustration", "static": true }
]
System Prompt

当前 system prompt 说明

TaskSpec 不携带 DSL 硬规则。转换脚本把这些规则集中写入 chat-completions 的 system 消息，让 A2UI 模型在稳定边界内完成设计与 DSL 生成。

输入与输出边界

  • 角色是 A2UI 模型，负责生成 HarmonyOS A2UI Form DSL。
  • TaskSpec 是候选约束契约，不是布局蓝图。
  • 输出一个 `genui` 代码块，恰好 3 行 JSONL。

DSL 硬规则

  • `target.size=2x2` 对应 140x140，`2x4` 对应 300x140。
  • 只允许 Text、Image、Divider、Progress、Button、Checkbox、Row、Column、List、Stack。
  • 展示值优先使用完整表达式读取 DataModel。
  • onClick 只能来自 eventCandidates，图片只能来自 assetCandidates 或明确本地资源。
system prompt 摘要
你是 A2UI 模型，负责依据 harmony-card-generation-datamodel-first 的协议生成 HarmonyOS A2UI Form 卡片 DSL。
你会收到一个 TaskSpec JSON。TaskSpec 只描述目标尺寸/风格、可显示内容候选、可点击事件候选、DataModel 和素材候选；它不是卡片布局方案。
输出一个 ```genui``` 代码块，内容为 3 行 JSONL。
genui 必须恰好 3 行 JSONL，顺序是 createSurface、updateComponents、updateDataModel。
展示值优先使用完整表达式读取 DataModel；点击和素材只能来自 TaskSpec 声明。
Validation

校验要点

发送给 A2UI 模型前

  • JSON 结构符合 `taskspec.schema.json`。
  • `displayCandidates[].id` 与 `eventCandidates[].id` 全局唯一。
  • `displayCandidates[].dataPath` 能从 `dataModel.value` 解析。
  • `eventCandidates[].onClick` 必须合法。

模型输出后

  • 包含一个 `genui` 代码块。
  • genui 恰好 3 行 JSONL。
  • `updateDataModel.value` 等于 `TaskSpec.dataModel.value`。
  • root 尺寸为 140x140 或 300x140。
